# S2 State and session lifecycle

Course material for section S2: progress files, exec plans, session handoff, stop and resume. Class
demo `make demo-2` (feature F2), assignment A2.

| Path | What goes there |
|---|---|
| [`concepts.md`](concepts.md) | The section's concepts, written from the sources in RESEARCH.md, and what the pilot found |
| [`demo/`](demo/README.md) | Live A/B runbook, with pilot run 2 output and dots |
| [`assignment/`](assignment/README.md) | Assignment brief, grading criteria, starter files, `make check-assignment-2` |
| `solution/` | Reference solution, grader, captured output (private until the review session) |
| [`post-class-reading/`](post-class-reading/README.md) | Three cited reading notes for after class |
| [`session-notes.md`](session-notes.md) | Notes for learners after the class: what was shown, what the A/B showed, common questions |
