# S2 State and session lifecycle

Course material for section S2: progress files, exec plans, session handoff, stop and resume, on
feature F2 (comments on issues) with a 12-turn first session. In class: the harness arm alone, live
("harness in action"), a pilot run replayed (`make replay RUN=ab-20261016-213317-9a0ec1`), and a
constructed example (`make example-2`). Assignment A2.

| Path | What goes there |
|---|---|
| [`concepts.md`](concepts.md) | The section's concepts, written from the primary sources ([REFERENCES.md](../../REFERENCES.md)), and what the pilot measured |
| [`demo/`](demo/README.md) | Class runbook: commands, order, console screens, what to watch, the replayed run, the constructed example, every pilot result, troubleshooting, fallback |
| [`assignment/`](assignment/README.md) | Assignment A2: task, grading criteria, starter files, `make check-assignment-2` |
| [`post-class-reading/`](post-class-reading/README.md) | Three cited reading notes for after class |
| [`session-notes.md`](session-notes.md) | Notes for learners after the class: what was shown, what the pilot measured, common questions |
