# Instructor materials

Everything the instructor needs to run Module 1, "Harness Engineering for Coding Agents", live and to
run the Thursday review. Status: M11 drafts; slots that need real run output are marked `[[PENDING]]`
with the milestone and command that fills them.

| File | Use it for |
|---|---|
| [run-sheet.md](run-sheet.md) | The 240-minute class, minute by minute: commands, console screens and keys, what to say during each run, known failure modes with exact messages, the replay procedure |
| [code-walkthrough.md](code-walkthrough.md) | Every walkthrough anchor (`scripts/anchors.py list`) with its file, lines, the code pulled from the repository, and talking points with source citations |
| [poll-questions.md](poll-questions.md) | One prediction poll per section and the final feature poll |
| [fallbacks.md](fallbacks.md) | Recorded runs per demo: how to record them, where they live, how to replay them with the RECORDING badge, what to say |
| [review-session-guide.md](review-session-guide.md) | The 2-hour Thursday review: 25 minutes per assignment, the A3 hidden-diff reveal, open questions |
| [engineering-notes/](engineering-notes/) | Provenance records from building the repository; not course material |

Related: the slide outline is [../slides/outline.md](../slides/outline.md); section demo runbooks are
in `submodules/0N-*/demo/README.md`; design and contracts are [../DESIGN.md](../DESIGN.md) (§13
console, §14 class plan) and [../CONTRACTS.md](../CONTRACTS.md).
