# M3 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the shipharness core (config, cost, events, sandbox, tracing, runner, harness hook framework, check framework, console SSE skeleton, CLI) and the TeamTrack base app, ending at tag `m1-base` with all unit tests green.

**Architecture:** One Python package `shipharness` under `src/` with small modules per CONTRACTS.md section; TeamTrack is a separate package under `teamtrack/` with its own tests. Every external dependency (OpenAI, LangSmith, Docker, subprocess) sits behind a protocol with a fake for unit tests, so the full suite runs on a machine with no Docker and no keys.

**Tech Stack:** Python 3.12, uv, Typer, pydantic 2 / pydantic-settings, structlog, openai 3.31, langsmith 0.14.9, FastAPI 0.143, SQLAlchemy 2.1, Alembic 1.20, Jinja2 + HTMX 2.0.11, sse-starlette, pytest 9.1, ruff 0.17, import-linter 2.15.

**Spec:** [DESIGN.md](../../../DESIGN.md), [CONTRACTS.md](../../../CONTRACTS.md) (v1.1), [RESEARCH.md](../../../RESEARCH.md).

## Global Constraints

- Python `>=3.12`; exact pins for every dependency (RESEARCH §4.7); lock with `uv lock`.
- Package name `shipharness`; CLI entry point `shipharness`.
- Model names only from config (`OPENAI_MODEL`, `OPENAI_EVAL_MODEL`); never hard-coded in code paths.
- Keys are `SecretStr`; never printed, logged, traced, or passed into a container (CONTRACTS §20).
- Unit tests (`tests/unit`, `teamtrack/tests/visible`) need no network, no keys, no Docker; live tests carry `@pytest.mark.live`.
- No emoji and none of the banned words (brief §1.3) in docs; `make lint-prose` enforces.
- Commits authored and committed as `ANI-IN <44803072+ANI-IN@users.noreply.github.com>`; no co-author or tool-attribution lines.
- Every Make target is a thin wrapper over `uv run shipharness ...` or `uv run pytest ...`, so Windows without make works.
- Status words in UI and CLI output always pair a symbol with a label.

## Review Focus

1. Model output with malformed function-call arguments (invalid JSON, wrong types) or an unknown tool name must produce a tool error result the agent sees, not a crash. Test in Task 7.
2. `apply_patch`/`read_file` paths that are absolute, contain `..`, or resolve through a symlink outside the workspace must be refused with `path_outside_workspace`. Test in Task 7.
3. Non-UTF-8 or very large tool output (binary file, 5 MB log) must be decoded with replacement and truncated to 8,000 chars with the trailer, with the full output saved. Test in Task 7.
4. OpenAI errors mid-run: rate-limit 429 retries with backoff; billing 429 (`insufficient_quota` etc.) and auth errors abort the arm as `ERROR` with a clear message, and the run log still gets `run_end`. Test in Task 9.
5. A console client that connects mid-run or reconnects with `Last-Event-ID` receives every later event exactly once. Test in Task 11.
